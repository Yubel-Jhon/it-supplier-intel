# 寻源 SOP(JD3:行业排名 / 分布 / 渠道 / 快速找到购买渠道)

从需求到定商五步,每步的产出物写清楚,不留「凭经验」。

## 五步流程

| 步 | 动作 | 产出物 |
|---|---|---|
| 1 定需求 | 需求单(模板 `templates/demand_brief.md`):品类/数量/预算/必达项 | 需求单 |
| 2 定渠道 | 按品类查下方「品类→渠道→比价方式」表,圈定 3+ 渠道 | 渠道清单 |
| 3 扫格局 | 行业排名/中标价扫描(口径见下),圈定备选池 | 备选池(≤5家) |
| 4 询报价 | 统一口径发 RFQ:数量/账期/SLA/含税/有效期写死 | 报价 JSON |
| 5 比价定商 | `scripts/compare_quotes.py` 出比价表+议价点+红旗 | 比价表,上会 |

## 品类 → 渠道 → 比价方式(核心映射)

| 品类 | 主要渠道 | 比价方式 |
|---|---|---|
| 云资源 | 原厂官网 / 云市场 / 总代 | **公开价目可监控**(降价公告+价目表),调价即触发重询 |
| AI 工具席位 | 原厂官网(企业档商务询价) | 个人档公开价锚定 + 三家商务报价 |
| 办公套件 | 原厂官网 / 授权代理商 | **公开企业版定价**可查,代理商折点可谈 |
| ERP 企业管理 | 原厂 / 授权代理商(项目制) | **无公开价,纯商务询价**,必走三方比价 |
| 开源自部署 | 开源社区,实施/支持服务走服务商 | 软件 0 元,**比价对象是实施服务报价** |
| 硬件/定制服务 | 1688 / 集采平台 | 见下方 1688 可选工具层 |

## 行业排名与格局扫描口径

- **政采网中标公告**(ccgp.gov.cn):真实成交价,比任何报告都硬——大单中标价=议价锚点。
- **IDC / Gartner / 信通院报告**:市场份额与魔力象限,LLM 搜「{{品类}} 市场份额 {{年份}}」。
- **云市场销量榜**:阿里云云市场/腾讯云市场同类目 TOP,反映真实采购流向。
- **融资/舆情**(信号层):供应商稳定性,进分级(QCDS)复审。

## 1688 可选工具层(实物/定制/服务外包寻源)

> 本 skill 主管线盯「软件云服务」供应商动态;实物采购、定制开发、驻场服务的寻源走 1688。集成方式:**可选外部工具,不装不影响主管线**。

- 工具:`superjack2050/1688-cli`(npm,阿里 1688 官方站,输出全 JSON,为 agent 设计)
- 安装与登录(用本人账号,扫码):
  ```bash
  npm i -g 1688-cli
  1688 login
  ```
- 寻源常用命令:
  ```bash
  1688 supplier search {{关键词}} --factory-only --json   # 只看工厂,砍掉贸易商
  1688 supplier research {{关键词}} --enrich top:5 --csv  # 供应商评分+信息补全
  1688 supplier inspect {{offerId}}                       # 验厂/信任信号
  1688 compare {{offerId1}} {{offerId2}}                  # 商品详情对比
  1688 seller inquire {{offerId}} "{{询价话术}}"           # 售前询价,支持 watch 盯回复
  ```
- 与主管线衔接:1688 拿到的报价/供应商信息,填进 `data/quotes/*.json`,照样走 `compare_quotes.py`。

## 供应商准入尽调(签约前)

- 工商/司法/经营异常:企查查/天眼查(人工),开源思路参考 `mtjikuzu/hermes-osint-skill`。
- 代理商核验:**向原厂核实授权资质**(防假代理),授权链路写进合同。
- 硬件必达项一票否决:安全/合规硬伤直接出局,不进比价。
