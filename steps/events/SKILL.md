# events · 大事即时(按维度分类)

与周更解耦:版本没动不代表行业没大事。**重大事件当天出即时简报,不等周更。** 目标:让产品决策者第一时间看到影响「差异化格局」的事件。

## 源

`sources.yaml` 里 `type: ai_media` 的头部公众号/媒体(量子位、机器之心、新智元、智东西、甲子光年、极客公园、雷锋网、钛媒体、APPSO、硅星人Pro)。无稳定 URL,靠 WebSearch 按名搜。

## 搜索策略

对每个 `ai_media` 源用 WebSearch 搜:`<公众号名> AI` 或 `<公众号名> <今天日期>`。重点抓**当天/近 1-2 天**的,每个源命中 3-5 条即可,搜不到跳过。

## 够格即时推送的判定

不是每条新闻都即时推。只推**会改变四维「差异」判断**的事件:

- 发布/大版本/能力放出 → 影响「能力迭代」
- 调价 → 影响「模型成本」
- 融资/收购/估值/上市 → 影响「资本/格局」
- MAU/用户规模公布 → 影响「目标人群」
- 纯公关稿/转载解读 → 不即时推,归入周报

## 归类口径(按影响维度,不是泛类)

| 类型 | 影响维度 | 判定 |
|---|---|---|
| 能力发布 | 能力迭代 | 新模型 / 大版本 / 新能力放出 |
| 成本调价 | 模型成本 | 定价 / 调价 |
| 资本动态 | 资本/格局 | 融资 / 收购 / 估值 / 上市 |
| 战略生态 | 战略 | 开源 / 合作 / 人才 / 组织 / 配售 |
| 监管合规 | 监管 | 政策法规 / 处罚 / 合规 |

## 重点标注

- 🚀 **重大升级**:模型正式版/大版本(能力发布里最重要)→ 红标。
- ✨ **新能力**:全新功能放出 → 紫标。
- 其余不加标注,保持精简。

## 核验与去重

- 沿用 `steps/verify/SKILL.md`:能力三档(📋/🎙️/📊)+ 媒体四态(原发/转载/转述/域名未核验)。
- 去重:同一事件多家报道只留一条,标多来源,取信息最全/最早为原发。
- 数字冲突标 ❌,保留多口径,注明出处日期。

## 产出

写 `data/raw/<今天>/events.md`,一行一条:

```markdown
| 类型 | 事件 | 重点标注 | 影响维度 | 来源 | 可信标记 |
|---|---|---|---|---|---|
| 能力发布 | DeepSeek V4-Pro 正式版 | 🚀重大升级 | 能力迭代 | 新浪 | 原发 |
```

供 update 合成进周报。

## 红线

- 不编造事件,搜不到就空着。
- 只收当天/近 1-2 天,别把旧闻当大事。
- 公众号「引用/解读」别当「原发」,分清转载/转述。
